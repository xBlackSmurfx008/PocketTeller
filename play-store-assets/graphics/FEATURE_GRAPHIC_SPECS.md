# Feature Graphic Specifications

## Requirements

- **Dimensions:** 1024 x 500 px (exactly)
- **Format:** PNG (24-bit) or JPEG
- **File size:** Max 1 MB
- **Color mode:** RGB

## Design Guidelines

### Layout Suggestion

```
┌──────────────────────────────────────────────────────────┐
│                                                          │
│  [Icon]  PocketTeller                                    │
│          Your AI-Powered Financial Coach                 │
│                                                          │
│                                [Phone Mockup]            │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

### Content Elements

1. **App Icon** (left side)
   - Use the existing app icon
   - Size: ~150-200px

2. **App Name** (center-left)
   - Text: "PocketTeller"
   - Font: Bold, modern sans-serif
   - Size: 80-100pt
   - Color: #7C3AED (brand violet) or white

3. **Tagline** (below app name)
   - Text: "Your AI-Powered Financial Coach"
   - Font: Regular, sans-serif
   - Size: 40-50pt
   - Color: Gray or white

4. **Phone Mockup** (right side, optional)
   - Show app dashboard
   - Use realistic phone frame
   - Angled slightly for visual interest

### Background

Choose one of:
- **Gradient:** Violet (#7C3AED) to blue (#3B82F6)
- **Solid:** Deep violet (#6D28D9)
- **Light:** White or light gray (if using dark text)

### Colors to Use

- Primary: `#7C3AED` (Violet)
- Secondary: `#3B82F6` (Blue)
- Accent: `#22C55E` (Green)
- Text: White or `#1E293B` (Dark gray)

## Tools

### Option 1: Canva (Easiest)
1. Go to: https://canva.com
2. Create custom size: 1024 x 500 px
3. Use template or design from scratch
4. Export as PNG

### Option 2: Figma (Design Tool)
1. Create 1024x500 frame
2. Design graphic
3. Export as PNG

### Option 3: Photoshop/GIMP
1. New file: 1024x500px, 72 DPI
2. RGB color mode
3. Design layers
4. Export as PNG

## Design Tips

✅ **Do:**
- Keep it simple and clean
- Use high contrast for readability
- Show what the app does
- Use brand colors consistently
- Make text large enough to read
- Leave some breathing room (padding)

❌ **Don't:**
- Use too much text
- Make text too small
- Use low-quality images
- Clutter the design
- Use non-brand colors
- Include screenshots (use phone mockup instead)
