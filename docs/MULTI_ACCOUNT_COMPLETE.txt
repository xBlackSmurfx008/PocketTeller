🎯 HOW IT WORKS
───────────────
1. User connects Bank #1 (e.g., Chase)
   → Creates plaid_item + accounts + transactions

2. User connects Bank #2 (e.g., Bank of America)  
   → Creates second plaid_item + accounts + transactions

3. User connects Bank #3 (e.g., Wells Fargo)
   → Creates third plaid_item + accounts + transactions

4. DEFAULT VIEW: All banks aggregated
   → Total balance across all accounts
   → All transactions combined
   → Unified spending insights

5. FILTERED VIEW: Select specific account
   → Shows only that account's transactions
   → Balance for that account only
   → Insights for that account

6. MANAGEMENT: Easy disconnect
   → Go to Account → Connected Banks
   → Click disconnect on specific bank
   → Transactions preserved, accounts removed
   → Can now connect a different bank
