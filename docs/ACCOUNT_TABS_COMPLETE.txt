🔘 ADD BANK BUTTON
──────────────────
Location: Right side of tabs (or below on mobile)
Shows When: User has < 3 banks connected
Hides When: Limit reached (3 banks)

Button Design:
  [+ Add Bank (2/3)]
   ↑      ↑      ↑
 Icon  Label  Remaining slots

Behavior:
  - Clicks button → Dialog opens
  - Plaid Link inside dialog
  - Connect bank → Tabs update
  - New tab appears for bank

🎯 USER FLOWS
─────────────

1. NO BANKS CONNECTED:
   → Shows welcome card with "Connect Bank" button
   → Click → Plaid modal → Connect
   → Tabs appear with "All Accounts" + bank name

2. ADD SECOND BANK:
   → Click [+Add Bank (2/3)] button
   → Dialog with Plaid Link
   → Connect → New tab appears
   → Can switch between: All / Bank1 / Bank2

3. SWITCH VIEWS:
   → Dashboard → Click "Chase Bank" tab
   → Financial snapshot updates to Chase only
   → Budget reflects Chase spending
   → Click "All Accounts" → Back to combined

4. REACH LIMIT (3 BANKS):
   → Connect 3rd bank
   → "Add Bank" button disappears
   → Tabs: All / Chase / BoA / Wells
   → To add different bank: Settings → Disconnect one

💾 DATA FILTERING
─────────────────
All Accounts Tab (accountFilter = null):
  - Fetch ALL accounts
  - Fetch ALL transactions
  - Show combined data

Individual Bank Tab (accountFilter = "item_123"):
  - Fetch accounts WHERE plaid_item_id_ref = "item_123"
  - Fetch transactions for those accounts
  - Show filtered data

📊 WHAT GETS FILTERED
──────────────────────
✅ Financial Health Snapshot (balances)
✅ Budget Overview (spending)
✅ Transaction List
✅ Spending Pie Chart
✅ Spending Insights

❌ NOT FILTERED (always global):
   - Goals
   - Bills
   - Account settings
