## 🌈 Material Design 3 Features

### Dynamic Color (Material You)
On Android 12+, your app can adapt its colors to the user's wallpaper:

```
User picks wallpaper
    ↓
System extracts dominant colors
    ↓
PocketTeller adapts theme
    ↓
Personalized, unique experience
```

### Edge-to-Edge Design
Modern Android pattern where content flows to screen edges:
- More screen space for content
- Premium, immersive feel
- Better for edge gestures

### Semantic Color System
40+ color tokens with specific purposes:
- `primary` - Brand identity, main actions
- `secondary` - Supporting actions
- `tertiary` - Accents, highlights
- `error` - Errors, destructive actions
- `surface` - Card backgrounds
- And many more...
