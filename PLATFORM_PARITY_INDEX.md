### Build & Deploy
```bash
# Android
npm run build && npx cap sync android && cd android && ./gradlew assembleDebug && cd .. && adb install android/app/build/outputs/apk/debug/app-debug.apk

# iOS
npm run build && npx cap sync ios && cd ios/App && open App.xcworkspace

# Web
npm run build && npm run preview
```

### Testing
```bash
# Android Chrome DevTools
# Open Chrome → chrome://inspect

# Android Logcat
adb logcat | grep PocketTeller

# List connected devices
adb devices

# Web lighthouse
npx lighthouse http://localhost:4173
```
